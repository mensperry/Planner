Planner

Enter adds a task. Start with ! to mark it important, or > to mark it up next (for example !> call the bank).

Click + on a task to add subtasks. Double-click any text to edit it.

Click a section's colour dot to change its colour. Double-click a section name to rename it.

Press Ctrl+N (or Cmd+N on Mac) to jump to the first “add a task” box.
