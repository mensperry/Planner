Planner

Enter adds a task. Start with ! to mark it important, or > to mark it up next (for example ! pay rent).

Hover a task and click ⋯ to add subtasks, flag it, move it to another section, or delete it. You can also drag a task onto another section.

Double-click any text to edit it. Click a section's icon to change its icon and colour.

Ctrl+N (or Cmd+N on Mac) jumps to the first “add a task” box.
